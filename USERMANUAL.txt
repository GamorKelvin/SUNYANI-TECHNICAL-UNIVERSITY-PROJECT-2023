Installation Process
-Extract the zip file on the pendrive to htdocs in the Xampp folder in drive C
-Start your Xampp server
-Open your browser
-Type localhost/phpMyAdmin
-Create new database and name it tutor
-In the database created, click on import and select the file name tutor from the htdocs folder in the xampp server
-After file is imported successful, now type Localhost/tutor/
-Now you are on the page called Private Tutor Finder!
